# excel_to_marc_iso.php — تبدیل اکسل به مارک و فایل ایزو (ISO 2709)

اسکریپت مستقل PHP (بدون نیاز به Composer) که فایل‌های اکسل را خوانده و به این خروجی‌ها تبدیل می‌کند:

| خروجی | توضیح |
|---|---|
| `<prefix>.iso` | فایل باینری **ISO 2709** (رکوردهای MARC پشت‌سرهم، قابل import در کتابخانه‌ها) |
| `<prefix>.mrk` | فرمت متنی MARC-MRK |
| `<prefix>.xml` | **MARCXML** (استاندارد ISO 25577 / LOC MARC21 slim) |
| `<prefix>.txt` | MARC21 خوانا با برچسب فارسی |

## فرمت‌های ورودی پشتیبانی‌شده
- `.xlsx` واقعی (ZIP/OOXML) — با ZipArchive داخلی PHP
- `.xls` ارسالی از خروجی‌های HTML کتابخانه‌ها (جدول HTML داخل فایل xls)
- `.csv`
- تشخیص خودکار UTF-8 / Windows-1256

## نقشه ستون‌ها (پیش‌فرض برای لیست کتب)
| ستون | فیلد MARC | معنا |
|---|---|---|
| A | `200$a` | عنوان اصلی |
| B | `200$c` | پدیدآور / مسئولیت |
| C | `606$a` | موضوع |
| D | `950$a` | تعداد/شماره جلد (فیلد محلی) |
| E | `210$b` | ناشر |
| F | `210$d` | سال نشر |
| G | `951$a` | دوره (فیلد محلی) |
| H | `010$a` | ISBN |
| I | `500$a` | یادداشت |

## نحوه استفاده (CLI)
```bash
php excel_to_marc_iso.php "لیست کتب کتابخانه مدرسه-اصلی.xlsx" output/books
php excel_to_marc_iso.php sample_members_aseman.xls members
# نقشه دلخواه: --map=ستون:تگ+زیرفیلد
php excel_to_marc_iso.php file.csv out --map=0:200a,1:200c,4:210b,5:210d
```

## تست انجام‌شده در این مخزن
- `لیست کتب کتابخانه مدرسه-اصلی.xlsx` → **۲۰۳۷ رکورد ISO 2709** تولید و ساختار همه رکوردها اعتبارسنجی شد (leader، directory، آفست فیلدها، پایان RS، UTF-8 معتبر). MARCXML نیز well-formed است.
- `sample_members_aseman.xls` (HTML-based xls) → ۱ رکورد.

## نکات
- کاراکترهای جداساز استاندارد: زیرفیلد `0x1F`، پایان فیلد `0x1D`.
- رهگذر (leader) ۲۴ کاراکتری با طول رکورد و base address صحیح ساخته می‌شود؛ اگر نرم‌افزار کتابخانه شما تگ‌های دیگری (مثلاً MARC21 خالص: 245/100/260/650) می‌خواهد، کافی است `$DEFAULT_MAP` یا پارامتر `--map` را تغییر دهید.
- ردیف سرستون (عنوان/ناشر/…) به‌صورت خودکار حذف می‌شود.
